aair web flasher

Flash and provision the tyclab firmware for the Aeris aair straight from the browser.

This page needs WebUSB and Web Serial. Use desktop Chrome, Edge or Opera.

1 · Flash

Writes system-part1 at 0x08020000 and system-part2 at 0x08060000 before the application. The unit needs bootloader v1003 or newer first — DFU cannot write the bootloader sector, so update it once over the listening-mode serial console as described in Hardware notes.

  1. Connect — pick the aair (2b04:c006) in the browser chooser waiting
  2. Enter DFU — skipped when the unit already shows as 2b04:d006 waiting
  3. Select DFU device — the unit re-enumerates under a new product id, and WebUSB permission is granted per product id, so the chooser appears a second time waiting
  4. Write firmware waiting
  5. Leave DFU — the unit reboots into the new firmware waiting

Do not unplug the unit while it is writing.

2 · Provision

The freshly flashed unit comes up in setup mode and takes one configuration line over USB serial. Connect, fill the form, send.
